# Security policy

Report suspected vulnerabilities privately to [contact@locatic.dev](mailto:contact@locatic.dev) with `Security report: Locatic` in the subject. Do not publish exploit details, credentials, or private member data in issues.

Include the affected revision, a minimal reproduction with your own test accounts, expected and actual behavior, and observed impact. Redact evidence and omit live tokens, other users' content, and database exports. Coordinate disclosure with maintainers.

Security fixes target the current default branch. Historical snapshots and forks have no promised maintenance window. This policy does not promise a response time or bounty.

Maintainers use the [dependency maintenance policy](docs/DEPENDENCY_MAINTENANCE.md) for updates, exposure assessment, and expiring exceptions. Its maintenance targets are not public response-time guarantees.
